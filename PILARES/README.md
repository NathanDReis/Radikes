# Pilares do Projeto

## 1. Mundo Aberto

O jogo possuirá um mundo contínuo, sem telas de carregamento entre regiões principais.

O mapa será expansível, permitindo adicionar novas áreas conforme o desenvolvimento evolui.

**Objetivos**

- Exploração livre
- Liberdade para o jogador
- Regiões distintas
- Crescimento contínuo do mapa

## 2. Sensação de Imensidão

O objetivo não é criar o maior mapa possível, mas fazer o jogador sentir que está em um mundo enorme.

Essa sensação será construída por meio de:

- montanhas altas;
- grandes vales;
- rios;
- lagos;
- florestas densas;
- planícies;
- horizonte distante;
- céu amplo;
- clima dinâmico;
- iluminação natural;
- boa distância de renderização.

Mesmo um mapa de 4–8 km² pode parecer gigantesco se o terreno for bem projetado.

## 3. Multiplayer Cooperativo

O jogo será cooperativo.

Características:

- até 4 jogadores;
- modelo Host + Clientes;
- funcionamento em rede local (LAN);
- sem servidores dedicados inicialmente;

## 4. Gráficos Realistas

O estilo artístico buscará um realismo moderno, utilizando os recursos da Unreal Engine 5.

Tecnologias previstas:

- Nanite;
- Lumen;
- Virtual Shadow Maps;
- Quixel Megascans (quando adequado);
- materiais PBR;
- vegetação detalhada;
- iluminação física.

O foco será em realismo consistente, e não em perseguir o máximo possível de fidelidade gráfica a qualquer custo.

## 5. Escalabilidade

O projeto será construído para evoluir continuamente.

Cada sistema deverá permitir expansão futura.

Exemplos:

- novas regiões;
- novos biomas;
- novos NPCs;
- novas missões;
- novos itens;
- novos veículos;
- novas mecânicas.
