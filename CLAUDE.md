# Instruções do Projeto

Este projeto documenta o design do jogo **Rádikes** (pilares, arquitetura, história, povos) nas pastas [PILARES/](PILARES/) e [ARQUITETURA/](ARQUITETURA/).

## Coerência com o que já está documentado

Antes de adicionar ou alterar qualquer conteúdo, verificar se é coerente com o que já está definido nos documentos existentes (pilares, história, linha temporal, povos, arquitetura, ou qualquer outra decisão já registrada).

Se uma adição ou alteração pedida pelo usuário contradizer algo já documentado, não decidir por conta própria: avisar o usuário sobre a contradição encontrada, explicar o conflito e perguntar como ele quer resolver antes de aplicar a mudança.
