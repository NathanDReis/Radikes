# Rádikes

Documentação de design de um jogo cooperativo em pixel art top-down, feito para Godot como hobby pessoal.

- [docs/](docs/) — toda a documentação do projeto: pilares, história do mundo e dos povos/reinos, arquitetura técnica e roteiro de desenvolvimento.

## Assets temporários

Os assets em [Tiny Swords/](Tiny%20Swords/) são placeholders usados para estruturar a base do jogo em [game/](game/) antes da produção de artes próprias. Vieram de [Tiny Swords](https://pixelfrog-assets.itch.io/tiny-swords) (Pixel Frog, itch.io) e serão substituídos.
