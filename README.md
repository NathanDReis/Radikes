# Rádikes

Documentação de design de um jogo de mundo aberto cooperativo, feito como hobby pessoal em Unreal Engine 5.

- [PILARES/](PILARES/) — pilares do projeto, filosofia, história do mundo e dos povos/reinos.
- [ARQUITETURA/](ARQUITETURA/) — arquitetura técnica (mundo, iluminação, estilo visual, primeiros passos).
- [simples/](simples/) — versão enxuta do mesmo projeto para Godot, com pixel art top-down em vez de realismo 3D.
