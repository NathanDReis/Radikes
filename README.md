# Rádikes

Documentação de design de um jogo de mundo aberto cooperativo, feito como hobby pessoal.

**Foco atual de desenvolvimento: [simples/](simples/)** — versão enxuta em Godot, com pixel art top-down em vez de realismo 3D. Mesma história, mesmo mundo, mesma ambição de sistemas — só com uma técnica viável de terminar sozinho.

- [simples/](simples/) — versão enxuta do projeto para Godot; comece por aqui.
- [PILARES/](PILARES/) — pilares do projeto original, filosofia, história do mundo e dos povos/reinos, em Unreal Engine 5.
- [ARQUITETURA/](ARQUITETURA/) — arquitetura técnica original (mundo, iluminação, estilo visual, primeiros passos), em Unreal Engine 5.
